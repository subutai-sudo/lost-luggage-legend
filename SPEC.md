# Lost Luggage Legends — Technical Specification

## 1. Concept & Vision

**Lost Luggage Legends** is an AI-run niche travel media site focused on *carry-on essentials for business travelers*. The site is the product — authoritative, specific, no-fluff gear guides and articles that rank and convert. The *system* behind it (AI content pipeline + QA + publish workflow) is the operational moat. The brand voice is confident, precise, and practical — like a seasoned road warrior sharing hard-won insights.

## 2. Design Language

**Aesthetic:** Clean editorial — think Wirecutter meetsafar. High information density, clear hierarchy, generous whitespace.
**Colors:**
- Primary: `#1a365d` (deep navy — trust, authority)
- Accent: `#dd6b20` (burnt orange — energy, CTA buttons)
- Background: `#fafaf9` (warm white)
- Text: `#1a1a1a` (near-black)
- Muted: `#6b7280` (secondary text)
**Typography:**
- Headings: `Inter`, 700 weight
- Body: `Inter`, 400 weight
- Mono (specs): `JetBrains Mono`
**Motion:** Minimal — 200ms ease transitions on links/buttons, no animation on content load.

## 3. Stack

- **Framework:** Astro 5 (static-first, zero-JS by default, excellent SEO)
- **Content:** MDX (markdown + components)
- **Hosting:** Vercel (zero-config, generous free tier, edge network)
- **CI/CD:** GitHub Actions (deploy on push to `main`)
- **Analytics:** self-hosted Umami (privacy-first, cookieless) — the single tracker, see §8
- **AI Content:** OpenAI GPT-4o via `src/scripts/generate-article.mjs` CLI tool
- **Domain:** `lostluggagelegends.com` (to be registered — DNS pointing to Vercel)

## 4. Site Structure

```
/                   — Homepage (hero + featured articles + categories)
/about              — About page (who we are, our methodology)
/articles/         — Article index (filterable by category)
/articles/[slug]    — Individual articles
/rss.xml            — RSS feed
/sitemap-index.xml  — Sitemap
```

**Categories:** `carry-on-bags`, `packing-essentials`, `tsa-rules`, `business-travel`, `gear-reviews`

## 5. Content Pipeline (Draft → Publish)

```
1. Generate  → src/scripts/generate-article.mjs (GPT-4o → MDX draft)
2. Store    → src/content/articles/[slug].mdx (draft flag)
3. Review   → Human review in GitHub PR
4. QA       → QA checklist (affiliate disclosure, alt-text, internal links, facts)
5. Publish  → Merge PR → GitHub Actions → Vercel deploy
```

## 6. On-Page SEO (LOS-3)

- Meta title: `{Article Title} | Lost Luggage Legends`
- Meta description: 150-160 chars, keyword-first
- Open Graph + Twitter cards on every article
- JSON-LD schema: `Article` schema with author, datePublished, image
- Canonical URLs on all pages
- `robots.txt` allowing all crawlers
- Sitemap auto-generated by @astrojs/sitemap

## 7. Affiliate Compliance

- `AffiliateDisclosure` component on every article page
- Links use `rel="sponsored nofollow"` for paid content
- Amazon Associates compliant link structure

## 8. Analytics (self-hosted Umami)

- Script injected in `<head>` by `src/components/UmamiAnalytics.tsx`, rendered only when `VERCEL_ENV === 'production'`
- Registration: website ID `0da19096-85a8-4489-b246-9151fa113f5b`; `data-domains` allowlists apex and `www`
- Host: `https://umami.scheduledloss.com` (self-hosted, PostgreSQL)
- A second provider (Plausible) was removed on 2026-11-23: both were firing on every page and double-counting visits
- Custom events: `article_read`, `affiliate_click`, `newsletter_signup`

## 9. GitHub Actions CI/CD

- Trigger: push to `main`
- Steps: install → build → deploy to Vercel
- Preview deployments for PRs
- Vercel token stored as GitHub Actions secret
